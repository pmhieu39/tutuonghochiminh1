# STUDYVERSE — Tư tưởng Hồ Chí Minh (EPU 0101003505)

Nền tảng học tập, luyện phản xạ, ôn tập ngắt quãng (SRS) và thi thử môn **Tư tưởng Hồ Chí Minh** dựa trên ngân hàng 301 câu hỏi trắc nghiệm gốc của Khoa Lý luận Chính trị và Pháp luật — Trường Đại học Điện lực (EPU).

## Cách chạy dự án
1. **Chạy trực tiếp ngay lập tức**: Mở file `studyverse_tthcm_epu.html` trên bất kỳ trình duyệt hiện đại nào (Chrome, Edge, Safari, Firefox) hoặc ngay trong cửa sổ Canvas.
2. **Chạy môi trường phát triển React + TypeScript + Vite**:
   ```bash
   npm install
   npm run dev
   ```
   Build bản production:
   ```bash
   npm run build
   ```
